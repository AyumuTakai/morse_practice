# アマチュア無線 受験勉強

[pages](https://ayumutakai.github.io/morse_practice/)

アマチュア無線技士の受験勉強用アプリです。分野ごと・級ごとにページが分かれていて、
よく使うページを「ホーム画面に追加」すると、アプリのように開けます(オフラインでも使えます)。

## ページ

まず級を選び(入口 → 級のページ)、その級で出題される練習を選びます。

| ページ | 内容 | 対象の級 |
|---|---|---|
| `index.html` | 入口(級を選ぶ。出題の目安、ホーム画面への追加方法) | - |
| `kyu-4.html` 〜 `kyu-1.html` | 級のページ(その級で出題される練習だけを並べる) | 各級 |
| `tree.html` | モールスの木(文字と記号を入れて覚える) | 3・2・1級 |
| `listen.html` | 聞き取り(1・3・5文字、速度の自動加速) | 3・2・1級 |
| `check.html` | 字句照合(過去問のB問題と同じ形式) | 2・1級(3級は選択式) |
| `qcode.html` | Q符号・略符号(一覧と4択クイズ) | 2・1級(3級は手順の中の一部) |
| `procedure.html` | 運用手順(選択式・並べ替え式、通信例) | 3・2・1級 |
| `keisan-1.html` | 1級の計算問題(9分野) | 1級 |
| `review.html` | 復習(学習記録から苦手を見つける) | 全級 |
| `settings.html` | 設定(速度・音程・文字の間隔・自動加速・サウンド) | 全級 |

選んだ級は端末に記憶され、練習ページのヘッダーに「← 3級」のように、その級のメニューへ戻るリンクが出ます。

**4級では、モールス・Q符号・略符号・無線電信の運用手順は出題されません。**
令和6年〜8年の過去問(1級・2級の法規)と、公式のCBT例題(3級・4級の法規、各3組)で確認しました。
3級・4級は本試験の過去問が公開されていないため、例題の範囲での確認です。

2〜4級の計算問題は準備中です(`keisan-2.html` などとして追加する予定です)。

## ファイル構成

- `assets/common.js` … 音声・設定・学習記録・ページ切り替え・オフライン対応(全ページ共通)
- `assets/common.css` / `assets/portal.css` / `tree.css` … 共通のスタイル(入口・級のページ用が portal.css)
- `assets/tree-lib.js` … モールスの木の生成と配置
- `assets/data-*.js` … Q符号・運用手順・計算の分野名のデータ(複数のページで使う)
- `manifests/` … ページごとの Web アプリマニフェスト(ホーム画面に追加したときの名前と起動ページ)
- `icons/` … ページごとのアイコン(色と模様が違います。模様はページの頭文字のモールス符号)
- `sw.js` … オフライン用の Service Worker(キャッシュするファイルの一覧を含む)

## 注意

- 学習記録と設定は、ブラウザの保存領域(`localStorage`)に保存されます。iPhone では、
  「ホーム画面に追加」したアプリごとに保存領域が別になるため、Safari で開いたときとは記録が共有されません。
- ファイルを追加・削除したときは、`sw.js` の `FILES` と、`CACHE` の版(`morse-practice-v3`)を更新してください。
- `ama1-keisan.html` は、1級の計算ドリルの元になった単独のページです(アプリとは独立しています)。
