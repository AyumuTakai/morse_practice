# iPhone / iPad 実機チェックリスト

対象: iPhone SE(第3世代)・iPad mini(第6世代)。URL は https://ayumutakai.github.io/amateur_radio_drill/

## 0. 準備
- [ ] Safari で上のURLを開く(Chrome ではなく Safari。ホーム画面追加は Safari から行う)
- [ ] サイレントスイッチがオフ、音量が上がっている
- [ ] 以前の「morse_practice」のホーム画面アイコンは、別物なので削除しておく

## 1. 表示(Safari)
- [ ] トップに 4級〜1級のカードが出る。級を選ぶとその級のメニューに進む
- [ ] 縦向き・横向きで、横スクロールが出ない(iPad は分割表示でも)
- [ ] ヘッダーのプルダウンで他のページに移動できる

## 2. 音(最初にボタンを押して鳴るか)
- [ ] 3級〜1級 → 聞き取り →「再生」で鳴る(最初の1回で鳴る)
- [ ] 設定の再生ボタンで鳴る。速度・音程を変えると変わる
- [ ] モールスの木で、マスを選ぶと鳴る(「サウンド」オン時)
- [ ] 画面ロック後・アプリ切り替え後に戻っても、再生ボタンで鳴る
- [ ] Q符号の「音」ボタンで鳴る

## 3. 級別の出題
- [ ] 4級: Q符号・運用手順・字句照合は「出題されません」の案内が出る
- [ ] 3級: 字句照合が4択、運用手順は「HH」の表記、Q符号は6件
- [ ] 2級: 字句照合は英字9字の○×
- [ ] 1級: 字句照合は10字/英字5字+数字の○×
- [ ] 1〜4級の計算ページが開き、答えを入力→判定→解説が出る(テンキーが出る)
- [ ] 聞き取りに「試験には出ません」の注意書きが出る

## 4. 学習記録
- [ ] 問題に答えたあと、復習ページに記録が出る
- [ ] 復習から「苦手だけ」を押すと、該当ページが開く(計算は `?weak=` つき)
- [ ] ブラウザを閉じて開き直しても、記録が残っている

## 5. ホーム画面に追加
- [ ] 共有ボタン →「ホーム画面に追加」→ 追加(ページごとに色・模様が違うアイコンになる)
- [ ] 例: 「3級 計算」と「聞き取り」の2つを追加して、それぞれ全画面(アドレスバーなし)で開く
- [ ] 追加したアプリからヘッダーのプルダウンで他のページへ移動できる
- [ ] 注意: ホーム画面のアプリごとに記録・設定は別になる(Safari とも共有されない)

## 6. オフライン
- [ ] 機内モードにする前に、各ページを一度ずつ開いておく(例: 使うページだけでよい)
- [ ] ホーム画面から開いたアプリを、機内モードで開いて表示される
- [ ] 機内モードのまま、計算や聞き取り(音)が動く
- [ ] 更新: オンラインで開き直したあと、もう一度開くと新しい内容になる(2回目の起動で反映)

## 7. 見つけたら控えること
- 端末・iOS のバージョン、ページ名、操作、画面のスクリーンショット
